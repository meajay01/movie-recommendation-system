How It Works

1. Movie Data

The system uses movie genres and descriptions from the dataset.

2. TF-IDF

Movie information is converted into numerical vectors using TF-IDF.

3. Cosine Similarity

The system compares movies and calculates how similar they are.

4. Recommendations

The five most similar movies are shown to the user.
